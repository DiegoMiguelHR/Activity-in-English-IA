Comparison of Classification Models

The Occupancy Detection Dataset: predict whether a room is occupied from environmental sensor data using four models from different mathematical families.

🎯 17,895 instances 📡 5 sensor features 🧮 4 models · 3 families 🔁 5-fold stratified CV ⏱ results: —

Project Overview

1 · Strategic Selection

Four models, one from each family: SVM & KNN (distance/geometric), Gaussian Naive Bayes (probabilistic) and Gradient Boosting (ensemble). Theoretical matrix with mathematical principle, outlier sensitivity, cost and distribution assumptions.

2 · Classification Challenge

Unified preprocessing pipeline (StandardScaler inside the pipeline, no data leakage). GridSearchCV hyperparameter optimization and stratified 5-fold cross-validation, scored with the macro F1-Score.

3 · The Verdict

Comparative analysis: best accuracy/generalization balance, whether complex models justified their computational cost, and how the decision boundaries behaved in relation to the dataset dimensionality.
